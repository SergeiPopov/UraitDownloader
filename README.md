# Программа (скрипт) для скачивания книг с сайта ЮРАЙТ urait.ru

## Инструкция по шагам:

1. **Ввести данные** аккаунта urait.ru (email и пароль).
2. **Придумать пин-код** — им шифруются данные аккаунта, чтобы не хранить данные в открытом виде. Этот же пин-код понадобится при следующих запусках.
3. Если необходимо **поменять** аккаунт или **забыли** пин-код, то нужно просто удалить файл рядом с программой [chipher_account_data](chipher_account_data) и авторизоваться заново, запустив программу.
3. **Убедиться, что есть доступ** к просмотру полной книги (аккаунта должны иметь полный доступ).
4. **Вставить ссылку** на книгу в правильном виде:
   - `https://urait.ru/bcode/<id>`
   - `https://urait.ru/viewer/<slug>-<id>`
5. **Дождаться завершения загрузки** — на экране отображается прогресс скачивания и конвертации страниц.
6. **Появившиеся файлы не удалять и не трогать** — не мешайте программе работать с временными файлами и итоговым PDF.
7. **Пользоваться полученным PDF** спокойно — готовый файл лежит рядом с программой.

## MACOS и LINUX

Для этих операционных систем нужно самостоятельно собирать бинарный файл или напрямую через python интерпретатор запустить файл main.py после установки всех зависимостей. 

**Действия для запуска:**
1) Скачать пакетный менеджер UV с официального сайта
https://docs.astral.sh/uv/getting-started/installation/

2) Установить зависимости командой 
```commandline
uv sync
```

3) Запустить скрипт командой
```commandline
uv run python3 main.py
```
